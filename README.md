# NeuroPrep — Nervous System Midterm 1

An interactive study website containing 100 advanced multiple-choice medical school practice questions, including timed exam mode, immediate-feedback study mode, explanations, anatomy practical figures, bookmarks, progress tracking, and local browser storage.

## Website

Publish this repository with GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.**

Your Pages URL will be: https://michaelspear290-stack.github.io/neuroprep-midterm/

`index.html` is self-contained; no build steps, dependencies, or server required.

**Content note:** Some anatomical figures are derived from provided lecture materials and may require permission for public redistribution. Verify rights before sharing publicly.
